📋 PASO 1: CLONAR EN KALI
──────────────────────────────────────────────────────────────

# Abre terminal en tu Kali VM y ejecuta:

cd ~
git clone https://github.com/TU_USUARIO/WiFi-Hacking-Toolkit.git
cd WiFi-Hacking-Toolkit

📋 PASO 2: DAR PERMISOS
──────────────────────────────────────────────────────────────

chmod +x install.sh
chmod +x wifi_cracker.sh

📋 PASO 3: INSTALAR HERRAMIENTAS (primera vez)
──────────────────────────────────────────────────────────────

Esto instalará:

✓ hcxdumptool + hcxtools
✓ hashcat
✓ wifite
✓ reaver + pixiewps
✓ fluxion

⚠️ CONFIGURAR USB WiFi EN VM
──────────────────────────────────────────────────────────────

Si usas VirtualBox:
1. VM apagada
2. Settings > USB
3. Enable USB Controller (USB 2.0 o 3.0)
4. Add USB Device Filter
5. Selecciona tu adaptador WiFi
6. Inicia VM
7. Devices > USB > Selecciona WiFi adapter

Si usas VMware:
1. VM > Removable Devices
2. Network Adapter > Connect (Disconnect from Host)

📝 CREAR REPOSITORIO EN GITHUB
──────────────────────────────────────────────────────────────

1. Ve a https://github.com
2. Click en "+" arriba derecha
3. "New repository"
4. Nombre: WiFi-Hacking-Toolkit
5. Descripción: Professional WiFi auditing toolkit for Kali Linux
6. Público o Privado (tu eliges)
7. NO marques "Initialize with README" (ya lo tienes)
8. Create repository
9. Copia la URL que te da
10. Usa esa URL en el git remote add origin
